# BOOK_OVERVIEW — 语料整体理解

> 阶段 0 产出（Adler 四步：结构 / 解释 / 批判 / 应用）
> 语料：本仓库《毛泽东选集》1–4 卷 txt、第五卷混编内容、毛泽东诗词、毛泽东画传十二卷、早期文稿。

---

## 一、结构（这本书/这批材料是怎么组织的）

### 1. 文本层

| 层 | 内容 | 性质 |
|---|---|---|
| 理论 | 《实践论》《矛盾论》《论持久战》《新民主主义论》 | 体系性论述，方法论的“总纲” |
| 战略 | 《中国革命战争的战略问题》《目前抗日统一战线中的策略问题》《目前形势和我们的任务》 | 在具体局势中做判断，方法论的“应用” |
| 组织 | 《关于纠正党内的错误思想》《反对自由主义》《整顿党的作风》《党委会的工作方法》 | 组织与作风，方法论的“落地” |
| 工作方法 | 《反对本本主义》《关心群众生活，注意工作方法》《关于领导方法的若干问题》 | 调查、群众路线、领导技术 |
| 建设 | 《论十大关系》《关于正确处理人民内部矛盾的问题》 | 社会主义建设时期的方法（第五卷） |
| 诗词 | 1921–1965 年约 30 首（本仓库 txt） | 自述性材料，情绪与气象 |
| 画传 | 十二卷 PDF | 他述性材料，视觉叙事 |

### 2. 时间层

- **1925–1927**：阶级分析、农民运动——方法论的起点是“分清敌友”。
- **1928–1934**：井冈山、根据地、反“围剿”——以弱胜强的实践。
- **1935–1937**：长征、遵义会议、两论——认识论与辩证法的系统化。
- **1938–1945**：抗战、统一战线、整风、七大——战略与组织的成熟。
- **1946–1949**：解放战争、建国——决断、追击、转型。
- **1950–1957**：建设、十大关系、人民内部矛盾——方法延伸到建设时期。

### 3. 逻辑层

不是按时间平铺，而是按“问题链”组织：

**怎么看世界（实践论）→ 怎么分析（矛盾论）→ 怎么打仗（战略学）→ 怎么组织（党建/整风）→ 怎么领导（党委会）→ 怎么建设（十大关系）**

这条链的每一环，都对应一簇可迁移的方法。

## 二、解释（核心概念在说什么）

### 1. 实事求是

不是“务实”的形容词，是一套认识程序：**占有材料 → 引出规律 → 回到实践检验**。它反对两种偏差：本本主义（从概念出发）和经验主义（从片段出发）。

### 2. 矛盾

不是“冲突”，是“事物内部的对立统一”。方法论价值在于**排序**：多数矛盾中找主要矛盾；一对矛盾中找主要方面；看双方如何转化。

### 3. 实践

不是“动手”，是“认识—实践—再认识”的循环。试点、复盘、推广，都是这个循环的组织形式。

### 4. 人民

不是修辞，是**力量来源与价值尺度**的统一。群众路线是“意见生产机制”：从分散意见到系统意见，再回到群众行动中检验。

### 5. 战略

不是“长远规划”，是**在力量不对称条件下选择作战形式与节奏**。纸老虎、持久战、集中优势、有理有利有节，都是这个问题的不同侧面。

### 6. 组织

不是“架构图”，是**基层细胞 + 硬纪律 + 干部 + 防骄**。支部建在连上、两个务必、党委会十二条，都是可操作的制度设计。

## 三、批判（这套材料的局限）

1. **历史语境**：多数文本写于战争与革命年代，“敌我”“斗争”“歼灭”有特定含义，直接搬到商业/日常会失真。
2. **晚年错误**：语料混编了 1966 年以后的材料，其中包含已被历史决议否定的做法。本 skill 明确排除这一层。
3. **版本混杂**：txt 包含原版五卷 + 静火/赤旗/草堂等汇编，部分文本非正式出版，不能一律当“原话”。
4. **单一人称**：材料是毛泽东视角，缺少对手、基层、普通人的完整声音；用它做历史判断会偏。
5. **成功者叙事**：文本经过选择与编辑，失败、犹豫、错误的部分被淡化。
6. **诗词的解释弹性**：诗词可作人格证据，但不能当史实；过度心理分析会失真。
7. **画传的宣传性**：十二卷是后人编绘，图像有美化与选择，不能当客观记录。

## 四、应用（这套材料能变成什么）

### 可迁移的方法（已做成能力卡）

| 方法 | 现代场景 | 卡 |
|---|---|---|
| 调查研究 | 决策前取证、用户研究、组织诊断 | `survey` |
| 矛盾分析 | 战略取舍、冲突定性、资源排序 | `contradiction` |
| 实践—试点 | 新业务、新制度、产品迭代 | `practice` |
| 战略判断 | 弱势竞争、长期项目、谈判 | `strategy` |
| 集中优势 | 预算/人力/注意力分配 | `concentration` |
| 群众路线 | 政策落地、社区/用户运营 | `mass-line` |
| 统一战线 | 利益相关者、联盟、跨部门 | `united-front` |
| 组织纪律 | 团队扩张、干部、防骄 | `organization` |
| 领导方法 | 会议、周报、班子 | `leadership` |
| 整风 | 复盘、反馈、冲突 | `self-criticism` |
| 长线转化 | 转型、影响力、长期主义 | `transformation` |

### 不可迁移/需转译的部分

- 军事指挥、情报、地下工作：需要专业知识，本 skill 不覆盖。
- 阶级划分、敌我定性：不用于当代人际/组织关系。
- 群众运动式的动员：不等于现代组织管理，需制度配套。
- 晚年政治运动：明确排除。

## 五、一句话

**这批材料真正可迁移的，不是某句结论，而是一套“看清—抓要害—组织力量—检验修正”的工作方式；诗词与画传则提供了这套方式背后的性格与气象。**
