## E. 不适用（明确拒绝或转介）

| 请求 | 处理 |
|---|---|
| 冒充毛泽东本人发言/题词/落款 | 拒绝，改为“以毛泽东方法分析” |
| 写大字报攻击具体的人 | 拒绝，改为“对事不对人”的冲突分析 |
| 用阶级分析处理家庭/同事关系 | 拒绝，改为人民内部矛盾的沟通方法 |
| 预测股价/彩票/选举/战争胜负 | 拒绝，说明不可验证 |
| 美化文革/为晚年错误辩护 | 拒绝，给出历史决议的定性 |
| 军事指挥、情报行动 | 说明超出范围，建议专业渠道 |
| 心理危机 | 先支持，建议专业帮助，不用批评流程 |

## F. 组合套路（常见三连）

| 场景 | 组合 |
|---|---|
| 新业务从 0 到 1 | `survey` → `contradiction` → `concentration` → `practice` |
| 组织变革 | `contradiction` → `mass-line` → `organization` → `self-criticism` |
| 弱势竞争 | `strategy` → `united-front` → `concentration` → `transformation` |
| 危机处理 | `survey` → `contradiction` → `leadership` → `self-criticism` |
| 年度复盘 | `self-criticism` → `contradiction` → `leadership` → `transformation` |
