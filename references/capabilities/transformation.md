# 长线转化（愚公移山 / 波浪式发展）

> 能力卡 `transformation` · 来源：《愚公移山》《星星之火，可以燎原》《关于重庆谈判》
> 一句话：**前途是光明的，道路是曲折的；星星之火可以燎原，但火要有柴。**

## I｜内核

长线转化处理的是**弱小的新事物如何变大**。四个判断：

1. **看实质，不看现象**：现在小，不等于永远小；现在强，不等于永远强。要看它有没有生命力（是否代表趋势、是否有群众基础、是否能自我迭代）。
2. **发展是波浪式的**：不是直线上升，是“扩张—巩固—再扩张”。每一次高潮之后要有巩固期，否则站不住。
3. **量变需要条件**：愚公移山不是“只要坚持就能移”，而是“山不增高 + 每天挖 + 子孙接着挖 + 感动上帝（群众）”。**没有条件的坚持，是自我感动。**
4. **战略耐心**：承认困难，分析困难，向困难作斗争；不贪便宜，不走捷径，准备走曲折的路。

---

## A1｜什么时候用

- 长期项目：品牌、研发、内容、公益、组织能力建设。
- 转型：从旧模式到新模式，短期看不到结果。
- 个人成长：学习、写作、健身、职业积累。
- 弱势开局：资源少、声量小、被忽视。
- 创业早期：找根据地、活下来、等待拐点。

**不适用**：窗口期很短、必须速战速决的机会；或方向本身已被证伪、应该止损的事。

## A2｜操作步骤

### 1. 判断“有没有生命力”

| 信号 | 有生命力 | 没有生命力 |
|---|---|---|
| 用户/群众 | 用过的人愿意再用、愿意传播 | 靠补贴/人情维持 |
| 趋势 | 符合长期结构变化 | 只是短期风口 |
| 迭代 | 每轮都能变好一点 | 反复犯同样的错 |
| 成本 | 边际成本递减/可积累 | 越做越重、越做越亏 |

**四条里三条为“有”，才值得长线投入。**

### 2. 建根据地（最小阵地）

- 选一个能守住的小场景/小区域/小人群。
- 在那里做到“别人绕不开你”，再谈扩张。
- 根据地要能自我造血，不能全靠总部输血。

### 3. 波浪式扩张

- **一波**：集中力量打下一个点。
- **巩固**：建制度、建团队、建供应链，把战果消化掉。
- **再一波**：以根据地为依托，向相邻场景扩张。
- 不跳过巩固期，否则“其兴也勃焉，其亡也忽焉”。

### 4. 积累转化条件

列出“从弱到强”需要的条件：
- 内部：产品、团队、资金、品牌、数据。
- 外部：政策、技术、用户习惯、竞争格局。
- 每季度问：这些条件是在变好，还是在变坏？

### 5. 等待/创造拐点

- 有些条件只能等（技术成熟、政策开放、对手犯错）。
- 有些条件可以造（标准、联盟、示范案例、舆论）。
- 在拐点到来之前，**活下来**是第一任务。

### 6. 巩固与防骄

- 每一次成功扩张后，主动放慢，补管理、补文化、补现金流。
- 问：“如果明天环境变差 30%，我们还能活吗？”

## B｜边界与反例

- **消极等待**：把“持久战”当不作为的借口，不积累、不试探、不改进。
- **星火没有柴**：只讲“星星之火可以燎原”，不看有没有可燃物（需求、渠道、团队）。
- **跳过巩固期**：扩张太快，管理、现金流、质量崩掉。
- **自我感动式坚持**：方向已被证伪，还用“愚公移山”给自己打气。
- **只讲精神，不讲条件**：愚公移山的前提是“山不增高”；现实中的“山”会增高（对手、成本、监管）。
- **长期主义变拖延**：用“长期”逃避当下的关键决策。
- **成功学化**：把复杂的历史条件简化成“坚持就能赢”，是对原意的歪曲。
