# 实践与试点

> 能力卡 `practice` · 来源：《实践论》《中国革命战争的战略问题》《反对本本主义》
> 一句话：**实践、认识、再实践、再认识；干起来再学习，干就是学习。**

---

## R｜原文依据

> “通过实践而发现真理，又通过实践而证实真理和发展真理。从感性认识而能动地发展到理性认识，又从理性认识而能动地指导革命实践，改造主观世界和客观世界。实践、认识、再实践、再认识，这种形式，循环往复以至无穷，而实践和认识之每一循环的内容，都比较地进到了高一级的程度。”
> ——《实践论》（一九三七年七月），《毛泽东选集》第一卷

> “感觉到了的东西，我们不能立刻理解它，只有理解了的东西才更深刻地感觉它。感觉只解决现象问题，理论才解决本质问题。这些问题的解决，一点也不能离开实践。”
> ——同上

> “读书是学习，使用也是学习，而且是更重要的学习。从战争学习战争——这是我们的主要方法。……常常不是先学好了再干，而是干起来再学习，干就是学习。”
> ——《中国革命战争的战略问题》（一九三六年十二月），《毛泽东选集》第一卷

> “你对于那个问题不能解决吗？那末，你就去调查那个问题的现状和它的历史吧！你完完全全调查明白了，你对那个问题就有解决的办法了。”
> ——《反对本本主义》（一九三○年五月）

## I｜内核

认识不是一次到位，是**两次飞跃 + 无限循环**：

1. **感性 → 理性**：从具体材料中抽出规律（调查、归纳、建模）。
2. **理性 → 实践**：把规律放回现实去检验（试点、执行、复盘）。

关键点：

- **实践是检验真理的标准，但不是“干了就算数”**。要有预期、有指标、有对照，才知道是“干成了”还是“碰巧没死”。
- **试点是把风险装进小容器**。先在可承受的范围内试，成了再推广，败了也付得起学费。
- **失败是信息，不是判决**。但前提是复盘出“哪条假设错了”，而不是笼统地说“经验不足”。
- **理论不代替实践，实践也不代替理论**。没有理论的实践是盲动，没有实践的理论是空谈。

---

## A1｜什么时候用

- 新业务、新产品、新市场：不确定能不能成。
- 新制度、新流程、新考核：不知道会不会水土不服。
- 组织变革：怕一刀切引发反弹。
- 个人技能/习惯：道理都懂，就是做不到。
- 危机应对：需要在信息不全时快速行动、边打边修正。

**不适用**：后果不可逆、不可试点的高风险决策（如重大安全、法律、健康问题）；这类要先做尽调与预案，不能“先干了再说”。

## A2｜操作步骤

### 1. 写清楚假设

不要写“试试看”，要写：
> “如果我们做 X，那么 Y 指标会在 Z 时间内从 A 变到 B，因为……”

**没有假设的试点，最后一定会变成“感觉还不错”。**

### 2. 设计最小试验

| 要素 | 要求 |
|---|---|
| 范围 | 越小越好，但必须包含真实复杂性（不能只在“乖孩子”身上试） |
| 周期 | 足够看到信号，又不至于拖到无法止损 |
| 对照 | 有对比组/前后对比/同类参照 |
| 指标 | 1 个主指标 + 2 个护栏指标（防止按下葫芦浮起瓢） |
| 停止条件 | 什么情况下立刻停 |

### 3. 干起来，但带着记录

- 每周记一次：预期 / 实际 / 偏差 / 新问题。
- 记**具体事件**，不记“整体感觉”。
- 让一线的人记，不要只让项目经理汇总。

### 4. 复盘（不是总结成绩）

四问：
1. 哪些预期发生了？哪些没有？
2. 没发生的原因是什么——假设错、执行错，还是环境变了？
3. 有没有意外收获/意外伤害？
4. 下一轮改哪一个变量？

**复盘要能改掉一个具体做法**，否则等于没复盘。

### 5. 决定：推广 / 调整 / 停止

| 结果 | 动作 |
|---|---|
| 主指标达标，护栏没破 | 推广，但**波浪式**：先扩到相近场景，再扩到不同场景 |
| 主指标达标，护栏破了 | 先修护栏，不要急着推广 |
| 主指标不达标，但机制有价值 | 调整变量，再试一轮 |
| 主指标不达标，且伤到基本盘 | 停，认账，写清楚“此路不通” |

### 6. 把经验变成规则

试点的产出不只是“成/不成”，还要有一条**可复用的规则**：
> “在……条件下，做……会得到……；超过……边界就不成立。”

```markdown
**范围**：……（为什么选它；它是否包含真实复杂性）
**周期**：……
**主指标**：……；**护栏指标**：……
**对照**：……
**停止条件**：……
**记录方式**：……
**推广条件**：……（达到什么程度、在什么范围内推广）
**复盘时点**：……
```

## B｜边界与反例

- **盆景化**：给试点开小灶、派最强的人、给额外资源，结果不可复制。
- **幸存者偏差**：只看成功的试点，不看悄悄死掉的。
- **只试不结**：试点一个接一个，从不形成规则，组织没有积累。
- **用“实践”反理论**：拒绝任何模型和推演，把蛮干当务实。
- **不敢停**：明明信号已坏，因为“已经投入这么多”继续加码。
- **伦理边界**：不能拿员工、用户、学生做伤害性实验；涉及隐私、知情同意、公平性要先过。
- **不可逆的事不要试点**：安全、合规、重大声誉问题，先做预案和压力测试。
