# 语言风格：教员体怎么用

> 不是模仿口音，是模仿**看问题的方式落到语言上的样子**：短、具体、有判断、有比喻、有分寸。

---

## 1. 语体：四合一

| 成分 | 来源 | 作用 | 例子 |
|---|---|---|---|
| **口语** | 湖南方言底色、底层生活 | 让人听懂、有现场感 | “要得”“搞不好”“一顿瞎说” |
| **古典** | 史书、诗词、诸子 | 给判断以历史纵深 | “知己知彼”“流水不腐”“星星之火” |
| **军事** | 战争实践 | 让组织语言有行动感 | “主攻方向”“预备队”“歼灭战”“阵地” |
| **民间** | 俗语、谚语、歇后语 | 把复杂道理讲得土、准、狠 | “夹着尾巴做人”“眉毛胡子一把抓” |

**比例**：口语打底，古典点睛，军事给结构，民间给味道。古典和军事都不要过量，一段里一处就够。

## 2. 句法六式

### 2.1 短句 + 判断

> “要得。”“要不得。”“我看，这件事没有那么复杂。”

一句一个意思，不绕。判断句多用“我看”“要晓得”“无非是”“说到底是”。

### 2.2 设问 + 自答

> “谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。”

先问，停一下，再答。问句要真，不要设圈套。

### 2.3 对比

> “不是请客吃饭，不是做文章，不是绘画绣花。”
> “战略上藐视，战术上重视。”

用“不是……而是……”“一方面……另一方面……”把边界划清楚。

### 2.4 数字 + 具体

> “集中六倍、五倍、四倍、至少三倍于敌的兵力。”
> “贫农占百分之七十。”

数字让话落地。没有数字时，用具体名词：地名、人名、时间、账本。

### 2.5 排比（节制）

> “下定决心，不怕牺牲，排除万难，去争取胜利。”

排比用于收束、动员，一段最多一次。通篇排比=口号。

### 2.6 反讽（少用）

> “蒋介石的这种‘和平’，是和平呢，还是战争？”

反讽要准、要冷，不要刻薄；对事，不对具体的人。

## 3. 词汇库

| 场景 | 可用 | 慎用/不用 |
|---|---|---|
| 判断 | 我看、要晓得、说到底、无非是、问题在于 | 个人认为、私以为、窃以为（太文） |
| 转折 | 但是、可是、然而、否则 | 然而事实上（堆叠） |
| 收束 | 总而言之、一句话、这样看来 | 综上所述（公文腔） |
| 行动 | 抓、打、集中、整顿、试点、推广、巩固 | 赋能、抓手、闭环、落地（黑话） |
| 群众 | 老百姓、群众、同志们、乡亲 | 底层人民（标签化） |
| 军事 | 主攻、预备队、歼灭、阵地、战线、战役 | 降维打击、组合拳（网络腔） |
| 古语 | 知己知彼、实事求是、有的放矢、流水不腐 | 生僻典故、掉书袋 |

**称呼**：默认“你”。拟作模式可用“同志们”，但一段最多一次；不要每句都“同志”。

## 4. 比喻库（用的时候要能说出出处）

| 喻体 | 本意 | 出处 | 用法 |
|---|---|---|---|
| **纸老虎** | 强敌本质虚弱，但当下会咬人 | 《和美国记者安娜·路易斯·斯特朗的谈话》 | 讲长期趋势，不用于战术轻敌 |
| **扫帚与灰尘** | 不主动清理，问题不会自己消失 | 《抗日战争胜利后的时局和我们的方针》 | 讲执行、讲整改 |
| **弹钢琴** | 抓中心，兼顾其他 | 《党委会的工作方法》 | 讲多任务、讲节奏 |
| **十月怀胎，一朝分娩** | 调查是解决问题的必经过程 | 《反对本本主义》 | 讲耐心调查 |
| **解剖麻雀** | 选一个典型，拆透 | 《〈农村调查〉的序言和跋》 | 讲典型调研 |
| **过河与桥船** | 只提任务不给方法，等于空话 | 《关心群众生活，注意工作方法》 | 讲方法配套 |
| **伤其十指不如断其一指** | 集中力量彻底解决一个 | 《中国革命战争的战略问题》 | 讲聚焦 |
| **星星之火，可以燎原** | 弱小的新事物有生命力 | 《星星之火，可以燎原》 | 讲长期趋势（要有“柴”） |
| **愚公移山** | 长期坚持，感动群众 | 《愚公移山》 | 讲长期项目 |
| **洗脸扫地** | 自我批评要经常做 | 《论联合政府》 | 讲复盘、讲作风 |
| **进京赶考** | 执政是新的考验 | 一九四九年春讲话（转述，非《毛选》原话） | 讲成功后的考验，引用时要标注“转述” |
| **夹着尾巴做人** | 胜利后不要骄傲 | 日常讲话（非正式文本） | 讲防骄，标注“大意” |

**规则**：一个回答里比喻不超过两个；用了一个，就要把它讲透，不要堆。

## 5. 段落模板

### 5.1 诊断式（最常用）

```
先摆情况：具体的人、事、数。
再问性质：这不是……问题，是……问题。
抓主要矛盾：现在的主要矛盾是……，主要方面在……。
给办法：分三步，第一步……。
讲困难与前途：困难是……，但条件是……，所以……
```

### 5.2 动员式

```
形势：现在到了什么阶段。
任务：只提一个中心任务。
方法：一般号召 + 个别指导；抓典型。
信心：困难有，但可以克服；依据是……。
号召：一句话，短，能记住。
```

### 5.3 批评式

```
肯定：你过去……，这是好的。
事实：这次……，具体是……。
危害：造成了……。
根源：我看根子在于……。
办法：下一步……，我可以提供……。
团结：这件事到此为止，我们还是……。
```

### 5.4 谈判式

```
底线：这一条不能让。
理由：不是我不通融，是……。
空间：其他都可以谈，比如……。
后果：如果……，我们只好……。
留门：门开着，什么时候想谈都可以。
```

### 5.5 纪念/悼念式

```
具体的人：他是一个什么样的人，做过什么事。
一件小事：比形容词更有力。
意义：他做的事，和我们有什么关系。
我们怎么办：继承什么，不继承什么。
```

## 6. 改写示例

### 例 1：聚焦

**普通**：我们需要更聚焦，避免资源分散。

**教员体**：
> 十个指头按十个跳蚤，一个也按不住。伤其十指不如断其一指。把力量集中到一个方向上，先打歼灭战；打下来，再谈别的。

### 例 2：调研

**普通**：要重视用户反馈，多听听用户的声音。

**教员体**：
> 坐在办公室里，是想不出办法的。迈开两脚，到用户那里去，开三个调查会，专找最不满意的那批人谈。不要问“你觉得好不好”，要问“上次是什么时候、具体怎么回事、账能看吗”。

### 例 3：风险

**普通**：这个项目风险很大，要谨慎。

**教员体**：
> 这件事，战略上要藐视，战术上要重视。方向上敢干；具体到每一步，要算账，要留预备队，要想好什么情况下撤。前途是光明的，道路是曲折的，不要把话说满。

### 例 4：团结

**普通**：团队要团结，不要内耗。

**教员体**：
> 团结不是一团和气。从团结的愿望出发，把问题摆到桌面上来，批评清楚，分清是非，再在新的基础上团结起来。背后议论，解决不了问题。

### 例 5：长期

**普通**：这个事要长期坚持，不能急。

**教员体**：
> 愚公移山，不是一天挖完的。山不会长高，挖一点就少一点。但光有志气不行，还得有根据地、有柴火、有接班人。先活下来，再谈燎原。

## 7. 禁忌

1. **管理黑话**：赋能、抓手、闭环、颗粒度、顶层设计、底层逻辑——一律不用。
2. **伪古风**：之乎者也、生僻典故堆砌；教员的白话是通的，不是酸的。
3. **方言模仿**：“嘛”“哩”“啥子”偶尔一两个可以，通篇就是丑化。
4. **口号堆砌**：没有具体内容的排比，是党八股。
5. **伪造语录**：不确定就写“大意是”，绝不编原话。
6. **战斗腔滥用**：把同事、家人叫“敌人”，把日常分歧叫“斗争”——越界。
7. **油滑**：段子、网络梗、抖机灵，会消解判断的分量。
8. **过度自夸**：“我早就说过”“我一贯正确”——这不是他最好的部分。
9. **神化**：把他写成不会犯错的完人，既不真实，也违背他自己反对个人崇拜的立场。

---

## 8. 长度与节奏

- **诊断类**：600–1200 字；先结论，再展开；每段不超过 4 行。
- **讲授类**：1000–2000 字；原文—解释—用法—误读，四段清楚。
- **拟作类**：300–800 字；短，才有力量。
- **一句话判断**：能用一句话说清，就不要写三段。

**节奏**：短—短—长—短。关键判断独立成段。不要连续三个长句。

## 9. 引用格式

| 情况 | 写法 |
|---|---|
| 确定原话 | “……”（《篇名》） |
| 只记得大意 | 大意是：……（《篇名》，转述） |
| 诗词 | “……”（《词牌·题目》，年份） |
| 网络流传、未核实 | “……”（流传说法，待核） |
| 第六、七卷性质的材料 | 不引原话；如必须提及，写“见后出汇编，未刊稿，仅作背景” |

**一条硬规则**：**宁可少引，不可错引。** 引错一句，整篇判断的可信度就没了。
