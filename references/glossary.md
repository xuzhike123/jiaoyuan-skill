# 术语表

> 每条给：原义 → 现代转译 → 常见误用。

## 认识论

**实事求是**
- 原义：“实事”是客观存在的一切事物，“是”是内部联系即规律性，“求”是去研究（《改造我们的学习》）。
- 转译：从事实中找规律，不从本本/愿望中找答案。
- 误用：把它当“务实”“不吹牛”的同义词，忽略“求”的研究过程。

**调查研究**
- 原义：到群众中、到现场去，取得第一手材料，形成结论。
- 转译：决策前的取证过程，不是姿态。
- 误用：把汇报、二手报告、筛选过的座谈当调查。

**实践—认识循环**
- 原义：实践、认识、再实践、再认识，循环往复，一次比一次高。
- 转译：小步试错 + 复盘 + 迭代。
- 误用：用“实践”拒绝理论；或用“没时间”跳过复盘。

**本本主义**
- 原义：从书本/上级指示出发，不从实际出发。
- 转译：教条主义、照搬最佳实践。
- 误用：把“有理论”一律叫本本主义。

## 辩证法

**矛盾**
- 原义：事物内部对立统一的关系。
- 转译：结构性张力、利益/目标/认知的冲突。
- 误用：把“矛盾”当“吵架”“问题”。

**主要矛盾**
- 原义：复杂过程中起领导、决定作用的矛盾。
- 转译：杠杆点、胜负手。
- 误用：把“最紧急”当“最主要”；主要矛盾会转移，不能一劳永逸。

**矛盾的主要方面**
- 原义：一对矛盾中起主导作用、规定事物性质的一方。
- 转译：当前谁占上风、什么决定事情性质。
- 误用：与“主要矛盾”混为一谈。

**转化**
- 原义：矛盾双方在一定条件下向对立面转化。
- 转译：拐点、条件变化。
- 误用：把“转化”当“自然会变好”，忽略条件。

## 战略

**纸老虎**
- 原义：反动派本质虚弱，长期看不可怕。
- 转译：强敌的结构性弱点。
- 误用：战术上轻敌；精神胜利法。

**持久战**
- 原义：敌强我弱时，以时间换空间，分防御、相持、反攻三阶段。
- 转译：长期竞争的战略耐心。
- 误用：把拖延、无所作为叫持久战。

**歼灭战 / 击溃战**
- 原义：歼灭战彻底消灭对方有生力量；击溃战只是打跑。
- 转译：彻底解决问题 vs. 暂时缓解。
- 误用：把“压下去”当“解决了”。

**集中优势兵力**
- 原义：在决定点上形成数倍于敌的兵力。
- 转译：资源聚焦，局部压倒性投入。
- 误用：孤注一掷，不留预备队。

**根据地**
- 原义：能立足、能补给、能出发的战略基地。
- 转译：最小可行阵地、现金流业务、核心市场。
- 误用：把“根据地”当“舒适区”。

**战略上藐视，战术上重视**
- 原义：全体上敢赢，具体上谨慎。
- 转译：愿景乐观，执行敬畏。
- 误用：只学一半。

## 组织

**群众路线**
- 原义：从群众中来，到群众中去；一般号召与个别指导结合。
- 转译：用户/员工意见的集中—返回—检验循环。
- 误用：民粹、走过场、尾巴主义。

**统一战线**
- 原义：团结一切可以团结的力量，孤立主要对手。
- 转译：利益相关者联盟。
- 误用：无原则妥协；把对手叫敌人；丧失独立性。

**有理、有利、有节**
- 原义：自卫、必胜、适可而止。
- 转译：冲突的三条纪律。
- 误用：只讲“有理”，不讲“有利/有节”，变成纠缠。

**民主集中制**
- 原义：民主基础上的集中，集中指导下的民主。
- 转译：充分讨论 + 明确拍板 + 一致执行。
- 误用：程序民主、实质一言堂；或议而不决。

**支部建在连上**
- 原义：基层单位建立党组织，保证组织力。
- 转译：最小作战单元有负责人、有信息、有决策权。
- 误用：微观管理、层层审批。

**整风**
- 原义：通过学习、检查、批评与自我批评，整顿思想作风。
- 转译：组织复盘与作风整顿。
- 误用：批斗会、人人过关。

**惩前毖后，治病救人**
- 原义：总结过去错误以警戒未来；处理人是为了救人。
- 转译：复盘对事、处理对人留出路。
- 误用：借复盘整人。

**团结—批评—团结**
- 原义：从团结愿望出发，经过批评分清是非，达到新的团结。
- 转译：建设性冲突。
- 误用：只团结不批评，或只批评不团结。

**两个务必**
- 原义：务必谦虚谨慎、不骄不躁；务必艰苦奋斗。
- 转译：成功后的防骄机制。
- 误用：口号化，不落到待遇、决策、监督上。

## 领导方法

**弹钢琴**
- 原义：十个指头都动，但有节奏、有中心。
- 转译：抓中心，兼顾其他。
- 误用：平均用力，或只按一个键。

**抓而不紧，等于不抓**
- 原义：抓主要工作必须抓到位。
- 转译：关键任务要有节点、检查、升级机制。
- 误用：事必躬亲。

**胸中有数**
- 原义：对情况和问题要有基本的数量分析。
- 转译：关键指标清楚。
- 误用：数据崇拜，只看数字不看结构。

**安民告示**
- 原义：开会前通知，让人有准备。
- 转译：会议议程与材料提前发。
- 误用：临时开会、无准备决策。

**精兵简政**
- 原义：精简机构、提高效能。
- 转译：减少流程、缩短会议、一页纸沟通。
- 误用：简单裁员，不减事。

## 长线

**星星之火，可以燎原**
- 原义：弱小的革命力量有发展必然性。
- 转译：小趋势、早期势能。
- 误用：忽略“可燃物”（需求、渠道、团队）。

**愚公移山**
- 原义：长期坚持，感动群众，改变世界。
- 转译：长期主义 + 群众动员。
- 误用：方向已错还硬撑；只讲精神不讲条件。

**波浪式发展**
- 原义：扩张—巩固—再扩张，不是直线。
- 转译：增长要有巩固期。
- 误用：只扩张不巩固，或只巩固不扩张。

## 人物

**教员**
- 由来：延安时期对毛泽东的称呼之一，含“导师/先生”意。
- 本 skill：作为方法+人格的代称，不表示冒充本人。
- 注意：正式历史叙述中称“毛泽东”；“教员”是亲近称呼。
