# 总览：这套 skill 是怎么来的、怎么用

## 1. 来源

本 skill 从以下材料蒸馏：

| 材料 | 在本仓库的位置 | 用途 |
|---|---|---|
| 《毛泽东选集》第一至四卷 | `毛泽东选集/毛泽东选集.txt`（本 skill 转成 `sources/maoxuan.utf8.txt`） | 方法论主依据 |
| 《毛泽东选集》第五卷内容 | 同上（混编） | 社会主义建设时期方法，标注使用 |
| 《毛泽东诗词》 | `其他/毛泽东诗词.txt`、`其他/毛泽东诗词品读.txt` | 性格、情绪、文风 |
| 《毛泽东画传》十二卷 | `毛泽东画传/毛泽东画传之*.pdf` | 人格原型、视觉意象 |
| 《毛泽东早期文稿》 | `其他/毛泽东早期文稿.txt` | 青年思想，标注年代 |

**没有使用**：静火、赤旗、草堂等汇编卷（第 6–7 卷性质）的方法内容；这些材料只作为背景，不作为原话依据。

## 2. 蒸馏方法

采用“读—抽—验—卡—测”的流程（借 cangjie-skill 的 RIA-TV++ 思路，人工执行）：

1. **读**：通读篇目，建立篇目地图（`corpus-map.md`）。
2. **抽**：抽取可复用的方法单元（不是金句）。
3. **验**：每条方法要能在原文找到依据，且能回答“什么时候用、怎么用、什么时候失效”。
4. **卡**：写成 11 张能力卡（R 原文 / I 内核 / A1 场景 / A2 步骤 / E 模板 / B 边界）。
5. **测**：用 `test-prompts.json` 做触发与边界测试。

## 4. 三根柱子，一根脊梁

- **实事求是**：结论产生于调查之后。
- **矛盾分析**：抓主要矛盾，定主要方面，看转化。
- **人民立场**：为谁干、依靠谁。
- **意志**：持久、愚公、自我批评。

所有能力卡都是这四条的展开，不是四套互不相干的知识。

## 5. 阅读路径

| 你是 | 先读 |
|---|---|
| 第一次用 | `SKILL.md` → `cheatsheet.md` |
| 要解决具体问题 | `SKILL.md` 路由表 → 对应能力卡 |
| 对人物感兴趣 | `persona.md` → `voice.md` |
| 要查原话 | `quotes.md` → `corpus-map.md` |
| 要教别人 | `overview.md` → 能力卡 → `test-prompts.json` |

## 6. 版本与局限

- **版本**：v1.0，基于本仓库 txt 校对；引语行号可能随源文件更新而变化。
- **局限**：
  - 这是“方法论 + 人格”的蒸馏，不是历史研究；不提供史实考证。
  - 能力卡里的现代场景是**类比迁移**，不是历史原意；使用时需自行判断适用性。
  - 诗词解读有主观性；`persona.md` 明确区分“自述”与“他述”。
  - 不覆盖军事指挥、情报、外交等专业领域；这些需要专门知识。
- **更新**：新增材料时，先补 `quotes.md` 和 `corpus-map.md`，再改能力卡；不要直接改结论。

## 7. 一句话

**它不是让你“像毛泽东那样说话”，是让你在遇到硬问题时，先调查、再抓主要矛盾、敢下判断、也敢改。**
