## 七、常见误引（不要当原话用）

| 流传说法 | 实情 | 建议 |
|---|---|---|
| “与天奋斗，其乐无穷；与地奋斗，其乐无穷；与人奋斗，其乐无穷。” | 常被归为毛泽东早期文字，版本与出处有争议 | 如引用，注明“早期文稿，待核” |
| “落后就要挨打。” | 广泛流传，但并非《毛选》中的原话 | 作为“流行说法”，不加引号归给本人 |
| “真理往往掌握在少数人手里。” | 不是毛泽东原话 | 不要引用 |
| “你打你的，我打我的。” | 军事思想的口语概括，正式文本中的表述不同 | 可作“大意”，不加引号 |
| “三天不学习，赶不上刘少奇。” | 轶事性说法，无可靠文本 | 不用 |
| “进京赶考。” | 一九四九年春谈话中的说法，非《毛选》正式文本 | 引用时标注“转述” |
| “毛泽东说：知识分子是臭老九。” | 特定历史语境下的说法，来源复杂 | 不在本 skill 使用 |

## 八、引用格式

1. **原话**：`“……”（《篇名》）`
2. **诗词**：`“……”（《词牌·题目》，年份）`
3. **大意**：`大意是：……（《篇名》，转述）`
4. **待核**：`“……”（流传说法，待核）`
5. **第五卷**：`“……”（《篇名》，《毛泽东选集》第五卷）`
6. **未刊/汇编材料**：不引原话；如必须提及，写“见后出汇编，仅作背景”。

> **硬规则**：宁可少引，不可错引。一句错引，整篇判断的可信度就没了。
